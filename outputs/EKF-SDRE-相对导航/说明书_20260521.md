# 说明书

**案件名称**：一种基于EKF-SDRE紧耦合的航天器相对导航最优控制方法及系统

---

## 一、技术领域

本发明属于航天器自主导航与制导控制领域，具体涉及一种在椭圆轨道下仅依赖测角传感器（或距离+角度传感器）对目标航天器进行相对状态估计，并基于估计结果实时计算最优控制推力以实现交会接近的方法及系统。

---

## 二、背景技术

在航天器交会接近场景中，追踪航天器需通过机载传感器测量与目标航天器的相对几何关系，经滤波估计相对状态后，由最优控制器计算推力，逐步接近目标。该过程涉及三个核心环节：非线性轨道动力学建模、相对状态估计、最优控制。

当前，围绕上述三个环节及其组合，现有技术主要沿以下方向展开。

在基于扩展卡尔曼滤波器（EKF）的航天器相对导航方向，CN107830856B 公开了一种面向编队飞行的太阳TDOA量测方法及组合导航方法，利用太阳TDOA建立径向相对距离量测模型，融合火星方向量测和星间链路测距，通过EKF滤波实时估计编队卫星的位置和速度。但该方案仅解决状态估计问题，不涉及相对轨道控制，且采用日心绝对动力学，未涉及LVLH相对运动坐标系的非线性建模。CN105737834B 公开了一种基于轨道平根数的相对导航鲁棒滤波方法，利用CDGPS载波相位差分测量相对位置和速度，经EKF滤波得到平根数估计。但该方案基于CW线性相对运动方程，仅适用于近圆轨道编队，不适用于大椭圆轨道（偏心率0.5以上）的非线性动力学场景，且不涉及轨道控制。US8825399B2 公开了一种利用EKF对星载被动传感器视线测量进行滤波实现航天器自主导航的系统，但其面向单星绝对导航，不涉及双星相对状态估计和轨道控制。

在基于状态依赖黎卡提方程（SDRE）的航天器轨道控制方向，CN112346339A 公开了一种考虑目标加速度方向观测的微分对策制导律设计方法，使用SDRE方法求解制导律，但其面向导弹末制导场景，飞行时间短，动力学模型和测量环境与航天器椭圆轨道交会差异显著，且未涉及EKF状态估计。CN112000132A 公开了一种基于椭球体描述的航天器避障控制方法，采用SDRE设计吸引势函数以生成吸引控制力，但其面向避障控制而非交会控制，同样无EKF状态估计环节。A. Jagat 与 A. Sinclair 在《IEEE Transactions on Aerospace and Electronic Systems》(2017) 发表的"Nonlinear Control for Spacecraft Pursuit-Evasion Game Using the State-Dependent Riccati Equation Method"一文中，在LVLH坐标系下建立了椭圆轨道航天器相对运动模型，通过SDC参数化将非线性动力学表为伪线性形式，使用SDRE方法求解连续推力控制律。然而，该方案假设追踪航天器已知目标航天器的精确位置和速度（完美状态信息），未涉及传感器测量噪声下的状态估计环节，无法直接应用于真实传感器场景。

在不完全信息下的航天器相对轨道控制方向，CN121734696A 公开了一种基于Alpha-Zero的卫星交会机动决策方法，但其采用线性CW动力学模型，仅适用于近圆轨道，且脉冲变轨模型与连续推力场景不同，未使用EKF处理传感器测量噪声。Tang、Ye、Huang 在《MDPI Aerospace》(2021) 发表的"Incomplete Information Pursuit-Evasion Game Control for a Space Non-Cooperative Target"一文中，将目标航天器未知机动建模为有色噪声，利用EKF同时估计目标相对状态和未知控制参数，基于线性二次最优控制理论推导追踪航天器控制律。但该方案控制端采用线性二次最优控制（基于CW方程），在椭圆轨道（偏心率0.1以上）非线性效应显著时精度下降，EKF与控制器使用不同的动力学模型，存在模型不一致问题，且未利用SDC矩阵复用来统一估计与控制。

在SDRE滤波器（SDREF）用于相对状态估计方向，2016年《Advances in Space Research》发表的"Relative navigation for autonomous formation flying satellites using the state-dependent Riccati equation filter"一文中，将含J2摄动的非线性相对动力学参数化为SDC形式，使用SDRE滤波器替代EKF进行状态估计，但该方案仅解决估计问题，未与轨道控制器结合，且SDREF滤波器本身的计算复杂度高于EKF。

在仅测角航天器交会制导方向，CN121632163A 公开了一种基于二阶锥规划的仅测角多脉冲自适应闭环交会制导方法，在LVLH坐标系下基于CW方程构建仅测角相对导航动力学模型和测量模型，将制导燃料消耗与系统状态可观测性条件融合为二阶锥规划的多目标代价函数。该方案明确针对"相对导航与交会制导模型分开设计"的问题，但其采用CW线性动力学，仅适用于近圆轨道场景，不适用于大椭圆轨道的非线性动力学；控制端采用二阶锥规划（优化方法），需预先规划完整轨迹，而非基于当前估计状态实时反馈的闭环控制；无EKF滤波环节，仅通过二阶锥规划代价函数中融入可观测性指标来间接改善导航精度。

综上所述，现有技术存在以下主要缺点：

（1）估计与控制的动力学模型不一致。现有方案中，EKF常使用简化线性模型（CW方程）进行预测，而航天器实际运行于椭圆轨道，非线性效应显著，估计器与控制器基于不同精度的动力学模型，导致模型失配，降低整体性能。

（2）SDRE轨道控制假设完美信息，无法直接工程化。现有SDRE交会控制研究均假设追踪航天器已知目标航天器的真实状态，未考虑实际传感器仅能提供带噪声的角度或距离测量这一基本约束。

（3）代数黎卡提方程（ARE）求解在极端量级差异下数值不稳定。SDRE控制器需在每个控制步求解ARE，在航天器场景中，状态权重Q与控制惩罚R的Frobenius范数之比可达10¹³，哈密顿矩阵条件数极高，导致基于Schur分解的标准ARE求解方法频繁失败，缺乏针对性的数值稳定化手段。

## 三、发明内容

### 3.1 本发明所要解决的技术问题

本发明所要解决的技术问题包括：

（1）估计-控制紧耦合问题：如何在仅依赖测角传感器（或距离+角度传感器）的测量噪声环境下，使状态估计器与控制器共享同一非线性动力学模型，消除模型不一致性。

（2）大尺度差异下的ARE求解稳定性问题：如何在Q/R量级差距达13个数量级的条件下，稳定地求解代数黎卡提方程，确保每个控制步都能得到有效的控制律。

### 3.2 应用前提

本发明应用于双航天器交会接近场景。追踪航天器与目标航天器均环绕同一中心天体（如地球）运行，参考轨道为偏心率 0 ≤ e_c < 1 范围内的开普勒椭圆轨道。目标航天器在整个交会过程中保持无控自由飞行（不施加主动机动控制），仅追踪航天器执行机动以接近目标。追踪航天器具备星载导航系统（可获知自身惯性系下绝对位置和速度，经轨道根数转换为参考轨道 LVLH 系下的相对参考状态）以及面向目标航天器的星载测角传感器（可选配距离传感器）。

### 3.3 技术方案

为解决上述技术问题，本发明提供一种基于EKF-SDRE紧耦合的航天器相对导航最优控制方法，包括以下步骤：

步骤（1）：追踪航天器通过星载导航系统获取自身在参考轨道LVLH（Local Vertical Local Horizontal，当地垂直当地水平）坐标系下的绝对位置和绝对速度，记为 6 维状态向量 X_p。所述 X_p 由星载导航系统在惯性系下测得，经参考轨道实时姿态计算转换至 LVLH 坐标系。

步骤（2）：追踪航天器通过星载传感器获取目标航天器的测量值，所述测量值至少包括方位角和俯仰角。所述星载传感器为仅测角传感器时，测量值为方位角和俯仰角[az, el]，测量噪声协方差矩阵R_meas为2×2矩阵；当所述星载传感器同时提供距离测量时，测量值为[ρ, az, el]，R_meas为3×3矩阵。EKF预测步和更新步通过读取R_meas的维度自动适配测量方程和雅可比矩阵，无需修改算法主体逻辑。

步骤（3）：以追踪航天器与目标航天器的相对位置和相对速度为状态变量，通过扩展卡尔曼滤波器（EKF）对所述测量值进行滤波，得到相对状态的估计值x̂。状态变量为6维向量[Δx, Δy, Δz, Δẋ, Δẏ, Δż]ᵀ，其位置分量定义为Δx = x_P − x_E，Δy = y_P − y_E，Δz = z_P − z_E（下标P指追踪航天器，下标E指目标航天器），速度分量同理。

步骤（4）：利用所述追踪航天器自身状态X_p和所述相对状态估计值x̂，反推目标航天器的估计绝对状态X̂_e = X_p − x̂（位置部分与速度部分分别按对应分量相减）；记位置分量为X̂_e_pos = X_p_pos − [Δx, Δy, Δz]ᵀ。

步骤（5）：基于状态依赖系数（State-Dependent Coefficient，SDC）参数化方法，将非线性相对轨道动力学表为伪线性形式 ẋ = A_SDC·x + B·u，其中B为6×3控制输入矩阵，其上半部（前3行）为3×3零矩阵0₃ₓ₃，下半部（后3行）为3×3单位矩阵I₃，即：

```
B = [ 0₃ₓ₃ ]
    [  I₃  ]
```

利用追踪航天器位置X_p_pos和目标航天器估计位置X̂_e_pos，结合参考轨道参数（地心距离r_c、真近点角速度ν̇、角加速度ν̈），计算非线性引力差值项并构造SDC矩阵A_SDC。

具体而言，所述SDC矩阵A_SDC为6×6矩阵，其结构如下：左上角3×3子块为零矩阵；右上角3×3子块为3×3单位矩阵I₃；左下角3×3子块（A21）包含非线性引力差值项的SDC分解；右下角3×3子块（A22）仅包含LVLH坐标系面内（x-y平面）的科里奥利力耦合项。

A21子块的9个元素表达式为：

```
A_SDC[3, 0] = ν̇² + (b_x · Δx) / ρ²
A_SDC[3, 1] = ν̈ + (b_x · Δy) / ρ²
A_SDC[3, 2] = (b_x · Δz) / ρ²
A_SDC[4, 0] = −ν̈ + (b_y · Δx) / ρ²
A_SDC[4, 1] = ν̇² + (b_y · Δy) / ρ²
A_SDC[4, 2] = (b_y · Δz) / ρ²
A_SDC[5, 0] = (b_z · Δx) / ρ²
A_SDC[5, 1] = (b_z · Δy) / ρ²
A_SDC[5, 2] = (b_z · Δz) / ρ²
```

其中，b_x、b_y、b_z为追踪航天器与目标航天器所受中心天体引力加速度之差在LVLH坐标系x、y、z方向上的分量，其精确表达式为：

```
b_x = −μ(r_c + x_P) / r_P³ + μ(r_c + x_E) / r_E³
b_y = −μ y_P / r_P³ + μ y_E / r_E³
b_z = −μ z_P / r_P³ + μ z_E / r_E³
```

式中μ为中心天体引力常数，(x_P, y_P, z_P)、(x_E, y_E, z_E)分别为追踪航天器与目标航天器在LVLH坐标系下的位置分量，r_P、r_E分别为两航天器的地心距：

```
r_P = √((r_c + x_P)² + y_P² + z_P²)
r_E = √((r_c + x_E)² + y_E² + z_E²)
```

ρ = √(Δx² + Δy² + Δz²)为相对距离。

A22子块仅有两个非零元素：A_SDC[3, 4] = 2ν̇，A_SDC[4, 3] = −2ν̇，其余元素为零，对应LVLH面内的科里奥利耦合（z方向不参与面内耦合）。

所述SDC参数化通过将非线性引力差值除以相对距离的平方并乘以对应相对位置分量，将引力差表达为状态变量的线性函数形式，完整保留了椭圆轨道的非线性效应。

步骤（6）：以所述A_SDC为系统状态矩阵，B为上述定义的6×3控制输入矩阵，以控制惩罚矩阵R和状态权重矩阵Q为参数求解连续时间代数黎卡提方程（ARE）：

A_SDCᵀ P + P A_SDC + Q − P B R⁻¹ Bᵀ P = 0

得到6×6对称正定矩阵P。基于最优控制理论，计算最优推力u = −R⁻¹ Bᵀ P x̂，其中x̂为当前EKF估计的相对状态。

步骤（6）中求解ARE时采用辛平衡预处理，具体为：计算缩放因子α = √(||Q||_F / ||S||_F)，其中S = B R⁻¹ Bᵀ，||·||_F为Frobenius范数；对状态权重矩阵和控制惩罚矩阵进行对称缩放：Q_bal = Q / α，R_bal = R / α；以缩放后的Q_bal、R_bal代入ARE求解，得到P_bar；还原P = α · P_bar。该缩放保持了哈密顿矩阵的辛结构，且α取||Q||与||S||的几何均值，使缩放后两者的范数之比接近于1，从而显著降低哈密顿矩阵的条件数。

当所述辛平衡预处理后ARE求解仍失败时，自动降级为行列缩放策略：对A_SDC按行取最大绝对值倒数构造对角矩阵D，对系统矩阵和输入矩阵进行相似变换：A' = D⁻¹ A_SDC D，B' = D⁻¹ B；同步变换状态权重矩阵Q' = Dᵀ Q_bal D；以变换后的系统（A', B', Q', R_bal）求解ARE，得到P'；反变换还原P = D⁻ᵀ P' D⁻¹。

进一步地，ARE求解不要求每个控制周期都执行。当ARE求解间隔N_are > 1时，中间步复用上一次求解得到的P矩阵直接计算推力u = −R⁻¹ Bᵀ P x̂，仅在间隔达到N_are的整数倍步时才重新求解ARE。这种稀疏更新策略在控制精度损失可忽略的前提下，显著降低了星载计算平台的运算负担。

步骤（7）：以所述最优推力u作为加速度输入，驱动追踪航天器沿非线性相对轨道动力学传播，逐步接近目标航天器。所述非线性相对轨道动力学传播基于NERM（Nonlinear Elliptic Relative Motion，非线性椭圆相对运动）的13维常微分方程（追踪航天器6维+目标航天器6维+真近点角1维），使用Runge-Kutta方法（RK45）进行真实状态的数值积分。

步骤（8）：在状态传播后的新时刻，再次执行步骤（4）至（5）构造预测用SDC矩阵A_ekf，将A_ekf离散化为状态转移矩阵F（典型采用一阶欧拉离散化形式F = I + A_ekf·Δt，其中I为6×6单位矩阵，Δt为控制步长），执行EKF预测步；获取新的测量值后执行EKF更新步，得到更新后的相对状态估计值，返回步骤（6）。

需要特别指出的是，步骤（5）所构造的A_SDC在同一控制周期内既用于步骤（6）的ARE求解又作为该控制周期内非线性动力学的统一描述；步骤（5）和步骤（8）所构造的SDC矩阵采用相同的SDC参数化方法，且两处的目标航天器估计位置均由前述步骤（4）所述反推方式获得。这意味着EKF预测步的状态转移矩阵与SDRE控制器的系统状态矩阵源于同一非线性动力学模型，估计器与控制器共享单一非线性动力学信息源，从根本上消除了现有方案中估计器与控制器的模型不一致问题。

所述参考轨道为绕中心天体（如地球）的开普勒椭圆轨道，偏心率范围为 0 ≤ e_c < 1。当 e_c = 0 时退化为近圆轨道，此时 SDC 矩阵中的 ν̈ 项等于零，b_x、b_y、b_z 中的引力差值项相应简化，方法依然适用，覆盖了从近圆轨道至大椭圆轨道的全范围交会任务。

本发明还提供一种基于EKF-SDRE紧耦合的航天器相对导航最优控制系统，包括：

测量与传感模块，用于获取目标航天器相对于追踪航天器的方位角和俯仰角测量值。追踪航天器搭载的测角传感器实时测量目标航天器相对于追踪航天器的方位角和俯仰角，可选的测距传感器提供相对距离测量，测量值附有零均值高斯噪声。该模块的作用是为EKF提供原始观测量。

EKF状态估计模块，以相对位置和相对速度为状态变量，通过预测步和更新步对所述测量值进行滤波，输出相对状态估计值x̂。预测步利用从SDC矩阵构造模块获取的A_SDC构建离散化状态转移矩阵F = I + A_SDC·Δt，进行状态和协方差的一步预测；更新步在预测状态处线性化测量方程，计算卡尔曼增益并融合新测量值。该模块与SDC矩阵构造模块之间存在双向数据流：向SDC模块提供估计的相对状态以反推目标位置，同时从SDC模块获取用于预测的动力学矩阵。

SDC矩阵构造模块，其第一输入端连接所述EKF状态估计模块以接收所述相对状态估计值x̂，其第二输入端接收追踪航天器自身状态X_p，通过反推X̂_e = X_p − x̂获得目标航天器的估计绝对状态并取其位置分量X̂_e_pos，基于状态依赖系数参数化方法构造SDC矩阵A_SDC。构造过程为：根据追踪航天器位置X_p_pos（已知）和由EKF估计相对状态反推的目标估计位置X̂_e_pos，结合参考轨道参数（地心距离r_c、真近点角速度ν̇、角加速度ν̈），按权利要求2所述9个A21元素表达式以及A22两个面内科里奥利耦合项的形式，组装6×6的SDC矩阵A_SDC。

SDRE最优控制模块，以所述A_SDC为系统状态矩阵，以6×3控制输入矩阵B（其上半部为3×3零矩阵、下半部为3×3单位矩阵）求解代数黎卡提方程，得到对称正定矩阵P，计算最优推力u = −R⁻¹ Bᵀ P x̂。该模块内置辛平衡预处理单元，所述预处理单元计算缩放因子α = √(||Q||_F / ||S||_F)，对Q和R进行对称缩放后求解ARE，还原P = α · P_bar。当辛平衡预处理后ARE求解仍失败时，自动降级为基于A矩阵行列缩放的二次求解单元。

轨道动力学传播模块，以所述最优推力u为加速度输入，沿非线性椭圆相对运动方程（NERM的13维常微分方程）进行Runge-Kutta数值积分，更新追踪航天器和目标航天器的真实状态。

其中，所述SDC矩阵构造模块的输出端同时连接至所述SDRE最优控制模块的ARE求解接口和所述EKF状态估计模块的预测步接口，使得SDC构造模块在控制时刻构造的A_SDC用于ARE求解，在传播后新时刻再次构造的预测用A_SDC用于构建EKF离散化状态转移矩阵F；ARE求解端与EKF预测端在同一控制周期内共享同一非线性动力学描述。这一连接关系是本发明紧耦合架构的核心特征：同一SDC参数化方法产生的动力学矩阵同时服务于估计的预测和控制的计算，形成单一的、统一的非线性动力学信息源。

### 3.4 有益效果

与现有技术相比，本发明具有以下有益效果：

（1）估计-控制模型统一。SDC矩阵同时服务于EKF预测和SDRE控制，消除了现有方案中估计器（线性CW）与控制器（非线性SDRE）之间的动力学模型不一致。SDC参数化完整保留了椭圆轨道的非线性效应（含真近点角加速度ν̈项和引力差非线性项b_x/b_y/b_z）以及LVLH面内的科里奥利耦合，确保估计与控制共享同一精度的轨道动力学描述。

（2）真实传感器可直接使用。不同于现有SDRE控制研究假设完美状态信息，本方案原生支持仅测角传感器（方位角+俯仰角）或距离+角度传感器的含噪声测量输入，通过测量噪声协方差矩阵维度的自动判别适配两种测量模式，使非线性SDRE控制具备了工程可部署性。

（3）ARE求解鲁棒。辛平衡预处理针对Q/R极端量级差异场景进行专门数值稳定化，配合行列缩放降级策略，确保在13个数量级跨度的参数配置下ARE求解不中断。在典型仿真条件下，辛平衡预处理下ARE求解成功率为100%，而同等条件下无预处理的标准方法失败率约为15%至40%。

（4）可配置的求解频率，适合星载计算平台。支持稀疏ARE更新（相邻控制步复用上一次的P矩阵），在控制精度损失可忽略的前提下显著降低计算负担，适合星载计算资源受限的应用场景。

## 五、具体实施方式

### 5.1 系统架构

图1所示为本发明基于EKF-SDRE紧耦合的航天器相对导航最优控制系统的结构框图。该系统包括五个核心模块：测量与传感模块（1）、EKF状态估计模块（2）、SDC矩阵构造模块（3）、SDRE最优控制模块（4）和轨道动力学传播模块（5）。

测量与传感模块（1）为系统前端，追踪航天器搭载的测角传感器实时测量目标航天器相对于追踪航天器的方位角和俯仰角，可选配的测距传感器提供相对距离测量，所有测量值附有零均值高斯噪声。该模块的输出端连接至EKF状态估计模块（2）的测量更新接口。

EKF状态估计模块（2）以相对位置和相对速度组成的6维状态向量[Δx, Δy, Δz, Δẋ, Δẏ, Δż]ᵀ为状态变量。其预测步从SDC矩阵构造模块（3）接收A_SDC矩阵以构建离散化状态转移矩阵F（典型采用一阶欧拉离散化F = I + A_SDC·Δt）；其更新步接收测量与传感模块（1）的测量值，线性化测量方程并计算卡尔曼增益，输出相对状态估计值x̂。EKF状态估计模块（2）的输出端连接至SDC矩阵构造模块（3）和SDRE最优控制模块（4）。

SDC矩阵构造模块（3）具有两个输入端：第一输入端接收EKF状态估计模块（2）输出的相对状态估计值x̂；第二输入端接收追踪航天器自身状态X_p（含位置X_p_pos与速度）。模块内部通过反推X̂_e = X_p − x̂获得目标航天器的估计绝对状态并取其位置分量X̂_e_pos，结合参考轨道参数（地心距离r_c、真近点角速度ν̇、角加速度ν̈），按A21九个引力差SDC元素表达式以及A22两个面内科里奥利耦合项的形式，组装6×6的SDC矩阵A_SDC。该模块的输出端同时连接至SDRE最优控制模块（4）的ARE求解接口和EKF状态估计模块（2）的预测步接口，这一"一对二"的连接关系是实现紧耦合的硬件基础。

SDRE最优控制模块（4）以A_SDC为系统状态矩阵，以6×3控制输入矩阵B（其上半部为3×3零矩阵、下半部为3×3单位矩阵）为输入耦合矩阵，内置辛平衡预处理单元（41）和行列缩放降级单元（42）。辛平衡预处理单元（41）接收状态权重矩阵Q和控制惩罚矩阵R，计算缩放因子α = √(||Q||_F / ||S||_F)，执行对称缩放后调用ARE求解器；若求解失败，则触发行列缩放降级单元（42）对A_SDC进行行列均衡变换后再次求解。求解得到对称正定矩阵P后，计算最优推力u = −R⁻¹ Bᵀ P x̂，输出至轨道动力学传播模块（5）。

轨道动力学传播模块（5）接收最优推力u作为追踪航天器的加速度输入，沿NERM非线性椭圆相对运动方程的13维常微分方程进行Runge-Kutta数值积分，更新追踪航天器和目标航天器的真实状态（位置和速度）以及真近点角，使系统进入下一个控制周期。

### 5.2 方法流程

图2所示为本发明基于EKF-SDRE紧耦合的航天器相对导航最优控制方法的流程示意图。以下结合具体实施例，对每个步骤进行详细说明。

本实施例以地球椭圆轨道航天器交会接近为应用场景。参考轨道参数为：半长轴a_c = 15000 km，偏心率e_c = 0.5，对应轨道周期约5.08小时。引力常数μ = 3.986×10⁵ km³/s²。追踪航天器初始在LVLH坐标系下相对于目标航天器的相对位置为[500, 500, 500] km（对应初始相对距离约866 km），相对速度为[0.01, 0.01, 0.01] km/s。目标航天器在整个交会过程中保持无控自由飞行（不施加主动机动）。控制步长Δt = 10 s，交会距离阈值d_rendezvous = 100 m。追踪航天器仅配备测角传感器，测角噪声标准差为0.008°（即1.4×10⁻⁴ rad）。

**步骤S1：初始化。**

设定追踪航天器和目标航天器的初始绝对状态（位置和速度），设定初始真近点角ν₀。初始化EKF状态估计向量x̂₀（通常以初始相对状态加小扰动，或设为零向量配合较大初始协方差）和初始协方差矩阵P₀。本实施例取P₀ = diag(100, 100, 100, 1, 1, 1)（位置分量单位 km²，速度分量单位 (km/s)²），反映初始相对状态先验信息较弱。状态权重矩阵设定为Q = diag(1, 1, 1, 10, 10, 10)，即位置权重为1，速度权重为10；控制惩罚矩阵设定为R = 10¹³·I₃，其中I₃为3×3单位矩阵。ARE求解间隔N_are = 1（即每个控制周期均求解ARE）。

**步骤S2：轨道参数获取。**

根据当前真近点角ν，计算参考轨道在当前时刻的地心距离r_c、真近点角速度ν̇和角加速度ν̈。计算公式如下：

r_c = a_c(1 − e_c²) / (1 + e_c·cos ν)

ν̇ = √(μ a_c(1 − e_c²)) / r_c²

ν̈ = −2 ν̇² e_c·sin ν / (1 + e_c·cos ν)

这些轨道参数将用于后续SDC矩阵的构造。

**步骤S3：目标位置反推。**

追踪航天器通过星载导航系统（如星载GNSS接收机或地面测控上行）在惯性坐标系下获取自身绝对位置和速度，再经参考轨道实时姿态计算转换至LVLH坐标系，得到自身6维状态X_p（含位置X_p_pos和速度X_p_vel）。利用EKF当前输出的相对状态估计值x̂ = [Δx, Δy, Δz, Δẋ, Δẏ, Δż]ᵀ，反推目标航天器的估计绝对状态：

X̂_e = X_p − x̂

其中，位置分量为X̂_e_pos = X_p_pos − [Δx, Δy, Δz]ᵀ，速度分量为X̂_e_vel = X_p_vel − [Δẋ, Δẏ, Δż]ᵀ。这一反推操作利用了追踪航天器已知自身真实位置的优势，使得后续SDC矩阵的构造能够基于对目标位置的最佳当前估计。

**步骤S4：SDC矩阵构造。**

基于状态依赖系数（SDC）参数化方法，利用追踪航天器位置X_p_pos和目标航天器估计位置X̂_e_pos，构造6×6的SDC矩阵A_SDC。

SDC矩阵具有如下分块结构：

```
A_SDC = [ 0₃ₓ₃    I₃ₓ₃ ]
        [ A21      A22  ]
```

其中，0₃ₓ₃为3×3零矩阵，I₃ₓ₃为3×3单位矩阵。

A22子块（右下角3×3子块）仅包含LVLH坐标系面内（x-y平面）的科里奥利耦合，其结构为：

```
A22 = [ 0     2ν̇    0 ]
      [ −2ν̇   0     0 ]
      [ 0     0     0 ]
```

即仅有A_SDC[3, 4] = 2ν̇、A_SDC[4, 3] = −2ν̇两个非零元素，z方向不参与面内科里奥利耦合。

A21子块（左下角3×3子块）包含非线性引力差值项的SDC分解，是关键的非线性信息载体。引力差值在LVLH坐标系x、y、z方向上的分量精确定义为：

b_x = −μ(r_c + x_P) / r_P³ + μ(r_c + x_E) / r_E³

b_y = −μ y_P / r_P³ + μ y_E / r_E³

b_z = −μ z_P / r_P³ + μ z_E / r_E³

其中 (x_P, y_P, z_P) 取自X_p_pos，(x_E, y_E, z_E) 取自X̂_e_pos，r_c 为当前真近点角对应的参考轨道地心距，r_P、r_E 分别为追踪航天器和目标航天器至中心天体的地心距：

r_P = √((r_c + x_P)² + y_P² + z_P²)

r_E = √((r_c + x_E)² + y_E² + z_E²)

为实现SDC参数化（即将引力差表达为状态变量的线性函数形式），利用恒等式 b · 1 = b · (Δx² + Δy² + Δz²) / ρ² 进行分解。A21子块的9个元素为：

A_SDC[3, 0] = ν̇² + (b_x · Δx) / ρ²

A_SDC[3, 1] = ν̈ + (b_x · Δy) / ρ²

A_SDC[3, 2] = (b_x · Δz) / ρ²

A_SDC[4, 0] = −ν̈ + (b_y · Δx) / ρ²

A_SDC[4, 1] = ν̇² + (b_y · Δy) / ρ²

A_SDC[4, 2] = (b_y · Δz) / ρ²

A_SDC[5, 0] = (b_z · Δx) / ρ²

A_SDC[5, 1] = (b_z · Δy) / ρ²

A_SDC[5, 2] = (b_z · Δz) / ρ²

其中ρ = √(Δx² + Δy² + Δz²)为相对距离。当ρ趋于零（即两航天器非常接近）时，采用规则化处理（如取ρ与一个小正数ε的最大值）以避免除零错误。

上述SDC参数化的核心思想在于：将非线性引力差值除以ρ²后乘以对应相对位置分量，使得A_SDC与状态向量的乘积A_SDC·x̂能够精确还原非线性相对动力学方程的右侧函数。由于A_SDC的构造使用了EKF估计的相对状态反推的目标位置，因此该矩阵完整反映了当前估计信息下的非线性动力学特性。

**步骤S5：ARE求解与控制量计算。**

以步骤S4构造的A_SDC为系统状态矩阵，B = [0₃ₓ₃; I₃ₓ₃]为控制输入矩阵，结合状态权重矩阵Q和控制惩罚矩阵R，求解连续时间代数黎卡提方程（ARE）：

A_SDCᵀ P + P A_SDC + Q − P B R⁻¹ Bᵀ P = 0

得到6×6对称正定矩阵P。

**辛平衡预处理子步骤**：由于Q与S = B R⁻¹ Bᵀ的Frobenius范数之比在本实施例中约为10¹³量级（Q的对角元素为1至10，而R = 10¹³·I₃使得S的对角元素约为10⁻¹³量级），哈密顿矩阵的条件数极高，标准ARE求解器可能因数值不稳定而失败。为此，执行以下辛平衡预处理：

（a）计算S = B R⁻¹ Bᵀ；

（b）计算缩放因子α = √(||Q||_F / ||S||_F)，其中||·||_F为Frobenius范数；

（c）对称缩放：Q_bal = Q / α，R_bal = R / α；

（d）以缩放后的Q_bal、R_bal代入ARE求解器（如Python的scipy.linalg.solve_continuous_are或MATLAB的care函数），得到P_bar；

（e）还原P = α · P_bar。

该缩放策略的数学原理在于：若(A, B, Q_bal, R_bal)的ARE解为P_bar，则(A, B, α·Q_bal, α·R_bal)的ARE解为α·P_bar。选择α = √(||Q||_F / ||S||_F)使得缩放后||Q_bal||_F ≈ ||S_bal||_F，两者量级匹配，从而显著降低哈密顿矩阵的条件数，提升ARE求解的数值稳定性。

**行列缩放降级子步骤**：若辛平衡预处理后ARE求解仍失败（如在极端状态组合下），自动降级为行列缩放策略：

（a）对A_SDC按行取最大绝对值倒数构造对角矩阵D：D_ii = 1 / max_j |A_SDC[i, j]|；

（b）相似变换：A' = D⁻¹ A_SDC D，B' = D⁻¹ B；

（c）同步变换状态权重矩阵：Q' = Dᵀ Q_bal D；

（d）以变换后的系统（A', B', Q', R_bal）求解ARE，得到P'；

（e）反变换还原：P = D⁻ᵀ P' D⁻¹。

**控制量计算**：利用求解得到的P矩阵和当前EKF估计的相对状态x̂，计算最优反馈控制推力：

u = −R⁻¹ Bᵀ P x̂

该控制律为标准的最优状态反馈形式，其推导来源于最小化无穷时域二次型代价函数J = ∫(x̂ᵀ Q x̂ + uᵀ R u) dt。

**稀疏ARE更新**：在需要降低计算负担的场景中，可设定ARE求解间隔N_are > 1。例如，当N_are = 5时，仅在每5个控制步求解一次ARE并更新P矩阵，中间4步直接复用上一次的P矩阵，以x̂的最新值代入u = −R⁻¹ Bᵀ P x̂计算控制量。由于相邻控制步之间航天器状态变化有限，P矩阵的时效性下降对控制精度的影响在可接受范围内。

**步骤S6：状态传播。**

以步骤S5计算的最优推力u作为追踪航天器的加速度输入，沿NERM非线性椭圆相对运动方程进行状态传播。NERM的13维状态向量定义为[追踪航天器在惯性系（或参考LVLH参考点固连描述）下的位置(3维), 追踪航天器在同坐标系下的速度(3维), 目标航天器在同坐标系下的位置(3维), 目标航天器在同坐标系下的速度(3维), 参考轨道真近点角ν(1维)]。其常微分方程组包括：

（a）追踪航天器位置导数 = 追踪航天器速度；

（b）追踪航天器速度导数 = 中心天体引力加速度 + 控制推力u；

（c）目标航天器位置导数 = 目标航天器速度；

（d）目标航天器速度导数 = 中心天体引力加速度（目标在交会过程中无主动机动）；

（e）真近点角导数ν̇ = √(μ a_c(1 − e_c²)) / r_c²。

采用Runge-Kutta-Fehlberg方法（RK45）对该13维常微分方程组进行从当前时刻t到t+Δt的数值积分，得到下一时刻的真实状态。RK45方法具有自动步长控制和4阶/5阶嵌入式误差估计，适合航天器轨道动力学的高精度积分需求。

**步骤S7：EKF预测与更新。**

在状态传播后的新时刻t+Δt，再次执行SDC矩阵构造（与步骤S4的构造方法一致），得到预测用SDC矩阵A_ekf。由于此时尚未获得新时刻的测量值，A_ekf的构造使用EKF上一时刻的估计状态反推目标位置。

**EKF预测步**：构造离散化状态转移矩阵F = I + A_ekf·Δt（一阶欧拉离散化，Δt = 10 s足够小时近似精度满足要求），其中I为6×6单位矩阵。预测状态：

x̂_pred = F · x̂_prev

预测协方差：

P_pred = F · P_prev · Fᵀ + Q_ekf

其中，Q_ekf为过程噪声协方差矩阵，本实施例中位置分量对应元素设为5×10⁻⁴ km²，速度分量对应元素设为5×10⁻⁸ km²/s²。

然后，生成含噪声的模拟测量值。在本实施例的仅测角模式下，根据目标航天器的真实相对位置计算真实方位角az_true和俯仰角el_true，叠加标准差σ = 1.4×10⁻⁴ rad的零均值高斯噪声，得到模拟测量值[az_meas, el_meas]。

**EKF更新步**：在预测状态x̂_pred处线性化测量方程。对于仅测角模式，测量方程为：

h(x) = [az, el]ᵀ

az = arctan2(Δy, Δx)

el = arctan2(Δz, √(Δx² + Δy²))

测量雅可比矩阵H = ∂h/∂x为2×6矩阵（仅前3列非零，后3列为零，因测量方程不依赖速度分量）。记ρ_xy² = Δx² + Δy²，ρ² = Δx² + Δy² + Δz²，则H矩阵的非零元素为：

H[0, 0] = ∂az/∂Δx = −Δy / ρ_xy²

H[0, 1] = ∂az/∂Δy = Δx / ρ_xy²

H[0, 2] = ∂az/∂Δz = 0

H[1, 0] = ∂el/∂Δx = −Δx · Δz / (ρ² · √ρ_xy²)

H[1, 1] = ∂el/∂Δy = −Δy · Δz / (ρ² · √ρ_xy²)

H[1, 2] = ∂el/∂Δz = √ρ_xy² / ρ²

计算卡尔曼增益：

K = P_pred · Hᵀ · (H · P_pred · Hᵀ + R_meas)⁻¹

其中R_meas = diag(σ², σ²)为2×2测量噪声协方差矩阵。

更新状态估计：

x̂ = x̂_pred + K · ([az_meas, el_meas]ᵀ − h(x̂_pred))

更新协方差：

P = (I − K · H) · P_pred

当星载传感器同时提供距离测量时，测量方程扩展为h(x) = [ρ, az, el]ᵀ，其中ρ = √(Δx² + Δy² + Δz²)，H矩阵扩展为3×6（增加距离对位置分量的偏导数行：∂ρ/∂Δx = Δx/ρ，∂ρ/∂Δy = Δy/ρ，∂ρ/∂Δz = Δz/ρ），R_meas为3×3矩阵。EKF预测步和更新步通过读取R_meas的维度（2×2或3×3）自动判别测量模式并适配测量方程和雅可比矩阵的维度和内容，无需修改算法主体逻辑，实现了多传感器配置的即插即用。

**步骤S8：交会判断。**

计算当前相对距离d = ||[Δx, Δy, Δz]||。若d < d_rendezvous（本实施例中为100 m），则判定交会成功，流程结束；否则，返回步骤S2，进入下一控制周期。

### 5.3 技术效果

在上述实施例的参数配置下，追踪航天器利用仅测角EKF估计可在约3.7小时（约0.73个轨道周期）内完成对目标航天器的接近。ARE求解在辛平衡预处理下成功率为100%，而同等条件下无预处理的标准方法在仿真过程中约15%至40%的ARE求解步出现数值失败（具体比例取决于航天器的实时位置和几何构型）。控制推力范数的峰值和均值均在星载推进系统的能力范围内（峰值推力加速度约为10⁻³ km/s²量级，与R = 10¹³的设置一致，推力大小可通过调节R矩阵来控制）。

当采用稀疏ARE更新策略（如N_are = 5，即每50 s求解一次ARE）时，ARE求解次数降至原来的20%，而交会时间和最终交会精度仅产生约1%至3%的相对偏差，证明稀疏更新策略在显著降低计算负担的同时保持了对控制精度的有效维持。

### 5.4 参数调节说明

以下对关键参数的取值依据和调节原则进行说明，以便本领域技术人员根据不同的任务需求进行适配：

（1）**状态权重矩阵Q**：Q越大表示对相应状态分量收敛速度的要求越高。本实施例采用Q = diag(1, 1, 1, 10, 10, 10)，速度权重（10）大于位置权重（1），兼顾位置收敛精度和速度平滑性。当任务要求更快的交会速度时，可适当增大位置权重。

（2）**控制惩罚矩阵R**：R越大，推力越小、燃料消耗越低，但交会时间越长。本实施例中R = 10¹³·I₃使最优反馈推力u = −R⁻¹BᵀPx̂处于适中量级（峰值推力加速度约10⁻³ km/s²），与典型化学推力器能力匹配。当星载推进系统推力能力更强时，可适当减小R以加快交会；当燃料预算紧张时，可适当增大R以节省燃料。

（3）**控制步长Δt**：应在1 s至30 s之间选择。过大的Δt会导致离散化误差增大，影响EKF预测精度和SDRE控制的最优性；过小的Δt会增加计算负担而不带来相应的性能提升。本实施例选用10 s是精度与计算效率的折中值。本实施例为简化将控制周期、EKF周期、ARE求解周期统一为Δt = 10 s，工程实施时可根据需要独立设定三个周期（例如EKF周期更短以提高估计精度，ARE求解周期更长以降低计算负担）。

（4）**ARE求解间隔N_are**：星载计算资源充足时设为1（每步求解）；星载计算资源紧张时设为3至10之间的整数。N_are过大（如超过10）会导致P矩阵显著滞后于当前动力学，控制精度下降明显，不建议在偏心率大于0.3的场景中使用大间隔。

（5）**测量噪声标准差σ_ang**：应依据实际搭载的传感器技术指标设定。星敏感器级测角精度约为1×10⁻⁵ rad量级（角秒级），普通光学相机级约为1×10⁻⁴ rad量级。

### 5.5 其它实施方式

以上所述仅为本发明的优选实施例，并非因此限制本发明的专利范围。本领域技术人员在不脱离本发明技术原理的前提下，可对上述实施例进行调整和变化，例如：

（a）参考轨道偏心率e_c在0 ≤ e_c < 1范围内均可适用，e_c = 0时退化为近圆轨道，此时ν̈ = 0且引力差值项相应简化，方法依然有效，覆盖了从近圆轨道至大椭圆轨道的全范围交会任务。

（b）中心天体不限于地球，也可为火星、月球或其他天体，仅需将引力常数μ替换为对应天体的值。

（c）追踪航天器可额外搭载激光测距仪或雷达测距仪，将系统从仅测角模式切换为距离+角度模式，以获得更高的状态估计精度。

（d）EKF预测步中状态转移矩阵F的离散化形式不限于一阶欧拉（F = I + A_ekf·Δt），亦可采用更高阶的离散化方式（如二阶离散化F = I + A_ekf·Δt + (A_ekf·Δt)²/2或矩阵指数F = exp(A_ekf·Δt)）以在大步长场景下提高离散化精度。

（e）SDC动力学模型可扩展加入主要轨道摄动项（如地球扁率J2摄动、大气阻力等），通过在A_SDC中追加对应的摄动加速度SDC分解项实现，本发明的紧耦合架构和辛平衡ARE求解策略仍然适用。
